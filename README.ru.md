Интеллектуальная многоязычная система документооборота, бухгалтерии, складского учета и календарной автоматизации для предприятий, созданная на **Python 3.11+**, **Django 5.x**, **Tailwind CSS** и **мультимодальном ИИ Google Gemini**.

---

## 🌐 Поддерживаемые языки (Многоязычность i18n)

Интерфейс системы полностью переведен и доступен на **8 языках**:
- 🇬🇧 **English** (`en`)
- 🇷🇺 **Русский** (`ru`)
- 🇪🇸 **Español / Испанский** (`es`)
- 🇳🇱 **Nederlands / Нидерландский** (`nl`)
- 🇫🇷 **Français / Французский** (`fr`)
- 🇵🇹 **Português / Португальский** (`pt`)
- 🇨🇳 **简体中文 / Китайский** (`zh-hans`)
- 🇯🇵 **日本語 / Японский** (`ja`)

Переключение языка доступно в любой момент через выпадающее меню с флагами в верхней панели навигации.

## 🌟 Ключевые возможности

1. **Распознавание сканов и мультимодальный ИИ**:
   - Прием отсканированных PDF-документов и изображений (договоры, счета поставщиков, чеки, товарные накладные).
   - Точное извлечение контрагентов, позиций товаров, ставок НДС, банковских IBAN и ключевых дат.
   - Работает на базе сменных провайдеров Multi-LLM (**Google Gemini**, **OpenAI ChatGPT / GPT-4o**, **Anthropic Claude 3.7**, **DeepSeek V3 / R1**, **Alibaba Qwen** или локальный **Ollama**).

2. **Экран верификации Side-by-Side (Сравнение скана и данных)**:
   - Двухоконный интерфейс: скан документа слева, редактируемая структурированная форма справа.
   - Одно нажатие **«Подтвердить и внести в регистры»** мгновенно создает проводки, обновляет складские остатки и заводит задачи в календаре.

3. **Бухгалтерия и управление платежами (AP / AR)**:
   - **Кредиторка (AP)**: Исходящие счета поставщиков с отслеживанием сроков оплаты.
   - **Дебиторка (AR)**: Ожидаемые поступления от клиентов.
   - Гибкая фиксация платежей (частичная оплата, полное погашение, методы расчета, номера транзакций).
   - Учет чеков расходов и подотчетных сумм (мелкая касса).

4. **Склад и товарные накладные**:
   - Каталог товаров с артикулами (SKU), остатками на складе и предупреждениями о необходимости дозаказа.
   - Приходные и расходные накладные.
   - Одно нажатие **«Принять на склад»** автоматически пополняет остатки и создает журнал движения (`StockMovement`).

5. **Единый календарь задач с живой синхронизацией iCalendar**:
   - Интерактивный календарь FullCalendar.js с цветовой индикацией:
     - 🔴 **Красный**: Срок оплаты счета поставщика
     - 🟢 **Зеленый**: Ожидаемое поступление средств от клиента
     - 🟣 **Фиолетовый**: Окно принятия решения о продлении договора
     - 🟠 **Оранжевый**: Доставка партии товара по накладной
     - 🔵 **Синий**: Административная задача
   - **Живой iCal-канал (.ics)**: Защищенный токенизированный URL (`/calendar/feed.ics?token=...`) для мгновенной подписки в **Google Календарь**, **Apple Calendar**, **Microsoft Outlook** или **Thunderbird**.

6. **Проактивные напоминания и алерты**:
   - Ежедневный автоматический аудит (`manage.py run_reminders`):
     - Напоминания за 7, 3, 1 день и в день платежа.
     - Критические предупреждения по просроченным обязательствам.
     - Сроки уведомления по договорам.
     - Сигналы о низком остатке товаров на складе.
   - Всплывающее меню уведомлений («колокольчик») в шапке сайта.

7. **Встроенный AI-Copilot (Бизнес-ассистент)**:
   - Диалоговый помощник, доступный из боковой панели на любой странице.
   - Ответы на естественном языке на основе актуальных данных базы (*«Какие счета оплатить на этой неделе?»*, *«Покажи остатки на складе»*, *«Каково финансовое состояние компании?»*).
   - Полная поддержка всех 8 языков.

## 🚀 Быстрый старт

### 🔰 Предварительные требования: установка Python (один раз)

Для работы проекта требуется **Python 3.11 или новее** (поддерживаются Python 3.11, 3.12 и 3.13).

1. Скачайте установщик с [официального сайта Python](https://www.python.org/downloads/).
2. Запустите установщик. **КРИТИЧЕСКИ ВАЖНЫЙ ШАГ:** На первом же экране поставьте галочку:  
   ☑️ **Add python.exe to PATH**  
   *(Если пропустить этот шаг, терминал не сможет распознать команду `python`!)*
3. Нажмите **Install Now**.
4. Откройте папку проекта в Проводнике Windows. Нажмите на адресную строку вверху, введите `powershell` (или `cmd`) и нажмите <kbd>Enter</kbd>. Откроется окно терминала прямо в этой папке.
5. Проверьте установку:
   ```powershell
   python --version
   ```
   *(Терминал должен вывести `Python 3.11.x`, `3.12.x` или `3.13.x`)*.

---

### ⚡ Первоначальная настройка (5 минут)

Выполните эти шаги один раз в терминале из папки проекта:

#### 1. Создание и активация изолированного окружения
```powershell
# Создание виртуального окружения (.venv)
python -m venv .venv

# Активация (Windows PowerShell):
.\.venv\Scripts\Activate.ps1
```
> **Подсказка для Windows:** Если отобразилась ошибка красным цветом *`выполнение сценариев отключено в этой системе`* (*`running scripts is disabled on this system`*), выполните следующую команду и повторите активацию:
> ```powershell
> Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
> .\.venv\Scripts\Activate.ps1
> ```
> *(Либо используйте командную строку CMD: `.\.venv\Scripts\activate.bat`, либо macOS/Linux: `source .venv/bin/activate`)*.

После успешной активации в начале строки ввода появится индикатор `(.venv)`.

#### 2. Установка зависимостей
```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

#### 3. Настройка ИИ-ассистента (интерактивный мастер)
Запустите многоязычный мастер для выбора провайдера ИИ и сохранения API-ключа:
```powershell
python setup_llm.py
```
- Доступно на 8 языках: Русский, English, Español, Nederlands, Français, Português, 简体中文, 日本語.
- Поддерживает **Google Gemini** (*бесплатный тариф доступен в [Google AI Studio](https://aistudio.google.com/)*), **Ollama** (*100% бесплатно и локально без интернета*), **OpenAI**, **Claude**, **DeepSeek** или **Qwen**.
- *(Опционально)* Вы также можете настроить модель через Django CLI (`python manage.py configure_llm --list`) или в веб-интерфейсе по адресу `/assistant/settings/`.

#### 4. Инициализация базы данных и загрузка демо-данных
```powershell
# Применение миграций базы данных
python manage.py migrate

# Загрузка демонстрационных данных (рекомендуется: создает счета, контрагентов, товары на складе и договоры)
python manage.py seed_demo_data

# (Опционально) Создание администратора для доступа к /admin/
python manage.py createsuperuser
```

### 🏃 Повседневный запуск (запуск проекта в любое время)

В будущем для запуска приложения достаточно выполнить всего **две команды**:

```powershell
# 1. Активировать окружение (если еще не активно)
.\.venv\Scripts\Activate.ps1

# 2. Запустить локальный сервер
python manage.py runserver
```

Откройте в браузере: **[http://127.0.0.1:8000/](http://127.0.0.1:8000/)** 🎉

### ❓ Устранение неполадок (Частые вопросы)

| Ошибка | Причина и простое решение |
| :--- | :--- |
| **`python не является внутренней или внешней командой`** | Python был установлен без галочки **Add to PATH**. Перезапустите установщик Python, нажмите **Modify**, отметьте **Add Python to environment variables** и перезапустите терминал. |
| **`Невозможно загрузить файл Activate.ps1, так как выполнение сценариев отключено`** | Windows по умолчанию блокирует PowerShell-скрипты. Выполните `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser` или запустите через CMD: `.\.venv\Scripts\activate.bat`. |
| **`Error: That port is already in use`** | Порт 8000 занят другой программой или предыдущей сессией. Запустите на другом порту: `python manage.py runserver 8080`. |
| **`no such table: ...`** | База данных еще не инициализирована. Выполните: `python manage.py migrate`. |
